# 2026 Summer Internship — Orthosis & Prosthesis Portfolio

Orthosis & prosthesis digital modeling work from my internship — 3D scanning, mesh repair, and CAD/Rhino modeling of medical orthoses.

## Contents

- **Cervical collar** — Cervical collar (颈托) model, V1/V2 iterations, STL + Rhino + Wrap source
- **Left Knee Orthosis** — Left knee orthosis model, V1/V2 iterations, STL + Rhino source
- **Thoracolumbar Orthosis (TLO)** — Torso scan data, working files, and merged jacket model
- **Thoracumbar Orthosis V2** — Cervico-thoraco-lumbar orthosis, V1/V2 iterations
- **wrist_orthosis V1** / **wrist_orthosis V2** — Wrist orthosis, two design iterations
- **Ankle Foot Orthosis** — Right ankle/foot orthosis, V1/V2 iterations including two-part split and merged models
- **Simulated weight_bearing foot and ankle reconstruction** — Foot/ankle reconstruction under simulated weight-bearing, including two-part split versions and merged final
- **Digital model repair for orthosis fabrication** — Mesh cleanup/repair workflow for scan data used in fabrication (large raw/intermediate files excluded from the repo, see `.gitignore`)

Some intermediate/backup files over 50MB are excluded due to unstable upload bandwidth — see `.gitignore` for the list; they remain available locally.

## Formats

- `.stl` — mesh models
- `.3dm` — Rhino source files
- `.wrp` — Geomagic Wrap project files
